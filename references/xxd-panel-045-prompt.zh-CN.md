# XXD Panel 045｜治愈系圆润积木雕塑生产提示词

只处理当前新任务明确提供的这一张源照片。私下锁定身份、结构、姿态、方向、动作、功能、开口、关系、情绪含义与源图色彩，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

按照解构、筛选、提炼、重构的逻辑，把源图做成治愈系等距积木雕塑；圆润可触的模块保住独特体量、轴线、曲线、穿插、层叠、遮挡与负空间，但不做乐高式复制或简单像素化。

严格遵循这条因果链：分析体量、轴线、曲线、穿插与负空间 → 保留三个决定性线索 → 简化为圆润模块体块 → 通过叠放、嵌套、穿越、悬浮与有依据的错位构图 → 把源图颜色转译为更明亮清透的治愈层级 → 呈现纸浆、木质、粉蜡或柔性材质般哑光触感 → 让微排版进入缝隙与轴线。

## 硬性视觉要求

- 从总体体量、比例、轴线、曲线、姿态、方向、穿插、遮挡、开口、负空间或关系中保留至少三个源图专属线索。
- 使用圆润、简洁、可触的模块体块与真实等距纵深，按源图结构拼接、叠放、嵌套、穿越、悬浮或轻微错位，而不是机械爆炸拆件。
- 分析源图有生命力的主色、综合色温、明度层级、冷暖呼应与关键点色，转译为更明亮、干净、通透的治愈色，不引入原图不存在的颜色或固定色卡。
- 以主色面积、辅助层级、同源明度阶与一个极小鲜活点色建立节奏：柔和但有精气神，童趣但不甜腻。
- 使用纸浆、木质、粉蜡、粉笔或柔性复合材料般的哑光漫反射触感、圆润边角与轻柔影子；拒绝亮塑料、金属、厚重CG与廉价玩具。
- 用尺度、高低、前后、局部悬浮、疏密与留白形成一个雕塑焦点，而不是完整玩具场景。
